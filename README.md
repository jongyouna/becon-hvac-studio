# BECON cloud 로그인 UI 목업

LG BECON cloud (`beconcloud.lge.com`) 로그인 화면의 레이아웃과 스타일을 참고하여 만든 **정적 UI 디자인 목업**입니다.

## 안내
- 실제 인증 로직이 없습니다. 아이디/비밀번호, 구글 로그인, 구글 OTP 등 어떤 버튼을 눌러도 서버로 전송되는 데이터가 없으며, 화면에 안내 토스트 메시지만 표시됩니다.
- 디자인 참고 및 프론트엔드 레이아웃 학습용으로 제작되었으며, LG전자와 무관한 개인 프로젝트입니다.
- 실제 서비스에 사용하거나 사용자로부터 로그인 정보를 수집하는 용도로 사용하지 마세요.

## 실행 방법
정적 HTML/CSS/JS로만 구성되어 있어 별도 빌드 과정이 필요 없습니다.

```bash
# 저장소 루트에서
open index.html   # 또는 브라우저로 직접 열기
```

또는 간단한 정적 서버로 실행:

```bash
npx serve .
```

## 구성
- `index.html` — 로그인 화면 마크업
- `css/style.css` — 레이아웃/스타일
- `js/main.js` — 버튼/링크 클릭 시 안내 토스트만 표시하는 목업 스크립트
